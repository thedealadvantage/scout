# Scout, from The Deal ADVantage

This repository is the Claude plugin marketplace for **Scout**, deal-readiness software from The Deal
ADVantage (ADVOS Pro LLC). Scout works only with a Scout license; the plugin alone does nothing without one.

**Add it in Claude:** Customize > Plugins > Add > Add marketplace, enter `thedealadvantage/scout`, add **Scout**, and turn on
**Sync automatically** so Scout updates itself. Then open the plugin's Connectors tab and click Connect.
